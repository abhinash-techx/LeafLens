    Project Overview

    LeafLens AI: Enterprise Agitech Diagnostic & Severity Engine is an AI / Deep Learning based platform developed for the mini project "AI-Deep Learning Based Plant Disease Identification and Treatment Using MobileNetV4."

    The system uses Computer Vision and an optimized ONNX Runtime inference pipeline to analyze plant leaf images, identify potential diseases, estimate infection severity, and generate automated multilingual PDF diagnostic reports.

    Implementation Note

    This in-browser demo uses a client-side HSV color/lesion-analysis classifier (the classical computer-vision approach described in the report's Literature Review) to simulate the MobileNetV4/ONNX pipeline without requiring a server. The downloadable ZIP contains the full production-style FastAPI + Streamlit + ONNX Runtime + Docker implementation described in the report.

    Technology Stack

    MobileNetV4 ONNX Runtime FastAPI Streamlit Docker Docker Compose Computer Vision PDF Reporting
